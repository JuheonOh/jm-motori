# v5

v3 스냅샷을 기반으로 첫 화면만 v1의 전체 폭 배경 구도로 변경합니다. 문구와 나머지 구성은 v3를 유지합니다.

- `node scripts/build-v5.mjs`: v3에서 v5를 재생성합니다. 현재 src(v4)와 v1–v4는 변경하지 않습니다.
- `overrides.css`: 전체 폭 히어로, 16:9 썸네일, RSS 요약문 스타일. 모바일 첫 화면 좌우 20px 여백과 얇은 테두리·밝은 배경의 카드 구분을 포함합니다.
- 생성 스크립트는 고정된 v3 번들의 정확한 변경 위치를 검증하고, 위치가 달라지면 실패합니다.
- 네이버 RSS의 `type=s3` 정사각형 썸네일 대신 같은 이미지의 `blogfiles.pstatic.net` 원본을 요청합니다. 프록시도 원본 비율을 유지하고, CSS cover로 16:9 카드 너비를 채웁니다. 현재 4:3 원본은 좌우를 보존하며 위아래 일부가 잘립니다.
- RSS 제목과 summary를 임의로 작성하지 않습니다. 요약문은 데이터의 문구를 그대로 사용하며 화면에서만 3줄로 제한합니다.
