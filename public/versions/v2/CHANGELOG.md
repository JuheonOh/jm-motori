# v2 — 정비소 랜딩 페이지 중심으로 수정

## 바꾼 점

1. 가장 큰 영문 슬로건을 한국어 헤드라인으로 교체하고, ‘광주 MINI 전문 정비’를 첫 화면 상단과 헤더에 표시했습니다.
2. 전화 상담 버튼·전화번호·주소를 첫 화면에 배치했습니다. 실제 정비 작업 사진 자리는 오른쪽, 모바일에서는 상담 안내 다음에 배치했습니다.
3. 추상적인 증상 탐색 대신 정비 분야 6개와 구체적인 작업명을 표시했습니다. 관련 MINI 사례로 연결됩니다.
4. 긴 RSS 목록을 접고, 경고등·진동·냉각계통을 다룬 대표 MINI 사례 3개만 먼저 보여줍니다.
5. 전체 정비 기록의 검색·필터·모달·원문 링크는 유지합니다. 전문 분야와 실제 입고 차종을 구분합니다.
6. 정비 철학 영역을 줄이고, 방문 안내와 전화 상담을 강조했습니다. 모바일에서는 연락처가 외관 사진보다 먼저 나옵니다.
7. 사진 실패를 명시하는 대체 상태와 선택적인 실제 사진 내장 빌드를 추가했습니다. 다른 업체·생성 사진으로 대체하지 않았습니다.

## 바꾸지 않은 점

- MINI 전문이라는 사용자 확정 사항
- 아이보리·오렌지·차콜 색감
- RSS의 원문 제목, 일부 본문, 게시일, 사진 URL과 네이버 링크
- 기존 안내의 연락처·주소·영업시간
- 실제 운영 사이트와 GitHub 저장소

## 남은 확인 사항

원본 사진을 제작 환경에서 수신하지 못했으므로 실제 사진의 크롭과 화질은 미확인입니다. 전달된 캡처는 대체 화면입니다. 실물 사진 확보와 최종 운영 정보 확인 후 배포 검토가 필요합니다.
